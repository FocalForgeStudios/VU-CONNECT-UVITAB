VU Connect System Logic & Architecture

Technical guide on how all subsystems and data persistence operate.

1. Personal Email & Google Auth Engine

Enforces authenticated Google SSO or personal email OTP verification (Gmail, Outlook, Yahoo, iCloud, etc.) with a 60-second cryptographic token lifecycle. Students can freely use personal email addresses with no institutional email required.

2. Multi-Factor Matchmaking Algorithm

Compatibility scores are computed via an algorithmic blend of: Shared Course Code Intersection (40% weight), Mutual Academic Interests (35% weight), and Faculty Proximity (25% weight).

3. CatchUp State & Capacity Manager

Spontaneous meetups manage dynamic attendee capacity counters, preventing over-booking and allowing immediate join/leave state transitions synchronized with UI badges.

4. Single-File Vanilla Architecture & Offline Storage

Built in standard Vanilla HTML5, CSS3, and ES6+ JavaScript. All user-created catchups, discussions, chat messages, and match profiles persist in local browser storage across sessions.
